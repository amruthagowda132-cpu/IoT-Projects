Ultrasonic Sensor IoT Project

Description

This project measures the distance of objects using an HC-SR04 ultrasonic sensor and Raspberry Pi.

Components

- Raspberry Pi
- HC-SR04 Ultrasonic Sensor
- Breadboard
- Jumper wires

Programming Language

Python

Files

- main.py – Python source code
- Ultrasonic_sensor.mp4 – Circuit connection video

Output

Displays the measured distance in centimeters.
